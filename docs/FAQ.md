# 常见问题（FAQ）

## 登录相关

**Q：必须扫码登录吗？能不能免登录？**
必须。这是**你自己账号的数据**，只能由你本人登录。登录态保存在本机 `browser_profile/`，
之后一般不用重复扫码（视平台策略而定）。

**Q：多久要重新扫码？**
不定。如果突然抓 0 条、或脚本提示未登录，就重跑 `python run.py fetch` 再扫一次。

**Q：`browser_profile/` 能删吗？能分享吗？**
能删（删了就要重新扫码）。**绝对不能分享** —— 它等同于你的账号登录凭据。

## 抓取

**Q：收藏夹数量对不上，某些夹差 1~2 条？**
多半是原作者已删除/转私密/被下架。接口的 `total_number` 仍会计入这些作品，但内容不再返回。
换新会话再跑一次仍无新增即可判定，不必反复重试。

**Q：抓取很慢？**
正常。每个收藏夹需要「打开列表 → 点卡片 → 滚动翻页」。几百条收藏约 10–20 分钟。
脚本已经优化：只对"首页预览不够"的收藏夹才逐个点开。

**Q：报「raw fetch 返回空列表」，是被限流了吗？**
不是。缺签名的自建请求会被静默降级。**不要去拼接口 URL**，用 `fetch_gap.py`（驱动页面）即可。

**Q：我在网页上删掉的收藏，脚本还会抓回来吗？**
网页上删除只是标记（存浏览器本地 + 导出 `excluded.json`）。
把它放到 `data/excluded.json`，抓取和产出都会跳过这些条目。

## 转写

**Q：转写要多久？**
本机 CPU 上约 1–2 分钟/条（视视频长度）。500 条约 10 小时。
建议 `--limit 60` 分批跑，随时可以中断，重跑自动续。

**Q：模型下载很慢 / 失败？**
HuggingFace 在国内常连不通。用镜像：
```bash
pip install modelscope
python run.py fetch-model
```

**Q：为什么有的视频没有逐字稿？**
两种情况：① 纯音乐/无口播/图文帖 —— 脚本标记为「无语音」，这是正确结果；
② 直链过期下载失败 —— 重跑一次抓取刷新直链即可。

**Q：能换成更大的模型提高准确率吗？**
可以。改 `scripts/process_batch.py` 里的 `WHISPER_MODEL`（如 `medium`），
代价是慢 2–3 倍、内存占用更高。

**Q：转写会把我收藏的内容传到云端吗？**
不会。faster-whisper 全程本地推理；下载视频也是直连抖音 CDN，不经过任何第三方服务。

## 产出与网页

**Q：网页上的批注/标星/待办会丢吗？**
存在浏览器 localStorage（键名前缀 `dy_`），换浏览器或清缓存会丢。
重要改动可以用网页顶部的「导出」按钮导出 JSON，放回 `data/` 即可长期生效。

**Q：怎么把网页发给朋友看？**
`python run.py site` 生成 `dist/`（纯静态），可部署到任意静态托管。
注意：其中含你自己的收藏内容，公开前请确认意愿。

**Q：分类不合意怎么改？**
三层：① 网页里直接改（可导出 `overrides.json`）；② `data/video_major.json` 逐条改；
③ `config/categories.json` 改收藏夹→大类的映射。优先级从高到低。

**Q：`dashboard.html` 打开是空白页？**
说明生成的 HTML 有 JS 语法错误。跑 `python scripts/test_render.py` 看控制台报错，
或 `python scripts/legacy/_js_check.js` 做语法检查后重跑 `python run.py build`。

## 其他

**Q：能同时整理两个账号吗？**
把项目复制两份，各自独立的 `browser_profile/` 与 `data/` 即可。

**Q：会占多少磁盘？**
500 条收藏约 2–5GB（视频+音频+截图）。不想要截图可以关掉抽帧步骤。

**Q：支持 Windows 吗？**
主要开发环境就是 Windows，另外提供 macOS/Linux 的安装脚本。路径已做平台无关处理。

**Q：为什么不提供 Docker？**
需要图形界面扫码登录 + 本地 whisper 推理，容器化收益有限、体验更差。用虚拟环境即可。
